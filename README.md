# BACTERIO terrain

Application de terrain (hors ligne) pour le Générateur de Planning BACTERIO.
Téléphones et tablettes Android récents (Chrome), aussi sur PC.

- Ouvrir le lien une fois dans Chrome, puis menu ⋮ > « Ajouter à l'écran d'accueil ».
- Au bureau : Excel > ruban BACTERIO > « Préparer le téléphone » crée le pack terrain (.json).
- Sur le terrain : charger le pack, choisir le magasin, scanner, cocher les analyses, photographier.
- Au retour : « Créer le fichier retour », puis Excel > « Importer le retour terrain ».

Aucune donnée n'est envoyée sur internet : tout reste dans le téléphone jusqu'à l'export.
